# Império Logística — Route Canvas

- Mode: Operate. Leadership must understand the selected event, its current stage, the blocking condition, and the next decision within seconds.
- Approved direction: Route Canvas. Approved composition: `.impeccable/mocks/decision/route-canvas.png` — option A, “Rota equilibrada”.
- Audience: logistics coordinators on desktop and field leaders on mobile, often under time pressure and with mixed digital familiarity.
- Desktop hierarchy: light navigation → selected event and abstract operational route → today operations at right → people/vehicle/evidence base → one integrated next action.
- Mobile hierarchy: current event → compact route window around the active leg → blocking fact and required confirmations → one thumb-reachable action.
- Visual world: near-white ground, green-black text, course purple only for the active path/action, pale sage support, amber/red exceptions, readable workhorse sans, aligned legends and restrained contour cues.
- Memorable moment: selecting another event redraws one shared route in place; the screen never becomes a map and never claims live GPS.
- Truth boundary: synthetic data only. EstoqueNOW credentials, real GPS, camera enforcement and conflict-safe synchronization remain pending.
